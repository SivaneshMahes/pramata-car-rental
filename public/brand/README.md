# Brand assets

`mark.svg` is the Wheels 2 Go vehicle-and-road mark. Edit it directly to change its shape or blue. The text wordmark is in `src/components/Brand.jsx`.

`google-g.png` is the official Google sign-in G icon from https://developers.google.com/static/identity/images/g-logo.png, downloaded 7 October 2026. Use only with the Google sign-in action, retaining its colors and proportions. Guidelines: https://developers.google.com/identity/branding-guidelines.
