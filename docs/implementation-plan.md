# Implementation plan

Approved scope: all requirements in the assignment and the project design.

1. Create the schema, password/session authentication, server-side role enforcement, seed data, and configurable Google OAuth.
2. Build vehicle discovery and management, validated multi-image uploads, transactional booking/quote logic, status transitions, reviews, favorites, notifications and PDF invoices.
3. Build a responsive React interface with plain CSS, customer and owner dashboards, search/filtering, detail/gallery/calendar, forms, and complete interaction states.
4. Test security boundaries, date/money handling, booking races, lifecycle transitions, uploads, invoices and persistence. Run a production build and exercise both roles in a browser.
5. Document actual versions, setup, API, demo credentials, assumptions, common edits and feature coverage.

Implementation runs sequentially in this chat. No subagents or extra services are needed.
